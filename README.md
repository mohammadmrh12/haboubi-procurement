# نظام مشتريات مستشفى الحبوبي

واجهة عربية متجاوبة (RTL) كنسخة أولية لتدقيق ملازم احتياج 2026 وإنشاء مسودات تخويل واعتذار.

## التشغيل
افتح `index.html` بمتصفح حديث أو شغّل خادم ملفات ثابتة داخل هذا المجلد. استيراد Excel يستخدم SheetJS من CDN، لذلك يحتاج اتصال إنترنت عند تحميل المكتبة.

## ملاحظات سلامة
- هذه نسخة أولية وليست نظاماً رسمياً معتمداً بعد.
- يتم استيراد البيانات محلياً إلى المتصفح الحالي؛ لا توجد مزامنة بين الأجهزة.
- مراجعة الرموز الوطنية والتكرارات والمصادر مطلوبة قبل اعتماد أي مستند.
- احتياج الدواء لثلاثة أشهر = السنوي ÷ 4، والمستلزم لستة أشهر = السنوي ÷ 2، مع مراعاة وحدة التعبئة وسياسة التقريب بعد اعتمادها.
- لا ترفع ملفات المستشفى أو البيانات إلى مستودع GitHub. المستودع مخصص للشيفرة فقط.
