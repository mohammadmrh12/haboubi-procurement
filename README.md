# نظام مشتريات مستشفى الحبوبي

واجهة عربية متجاوبة (RTL) لبحث الأدوية والمستلزمات، استيراد ملازم Excel لعام 2026، مراجعة الرموز والاحتياج، وتجهيز مسودات التخويل والاعتذار.

## التشغيل المحلي
- شغّل الخادم عبر \`node server.js\` وافتح الموقع عبر \`http://127.0.0.1:8101\`؛ لا تستخدم خادماً ثابتاً لأن واجهات المصادقة والحفظ تحتاج API.
- مكتبة قراءة Excel مضمنة محلياً في \`vendor/xlsx.full.min.js\`، فلا يحتاج الاستيراد إلى تحميل المكتبة من الإنترنت.
- يمكن تحديد عدة ملفات Excel في عملية استيراد واحدة.
- سجلات المستخدمين والبيانات والإعدادات تحفظ على الخادم داخل `data/private/`، وهي مستثناة من Git. لكل كود مساحة بيانات وسجل عمليات مستقلان.
- تسجيل الدخول يقبل الأكواد العشرة المحددة في `server.js`. خيار «تذكرني» يستخدم كوكي موقعة، HttpOnly وSecure وSameSite=Strict، صالحة لسنة.
- كل عملية معاينة/طباعة تحفظ موادها والسنة واسم المخوّل وأمين المخزن، وتظهر تحت «العمليات السابقة» مع عرض التفاصيل وإعادة الطباعة.
- يعمل خادم Node على المنفذ 8101 خلف Cloudflare Tunnel؛ خدمة LaunchAgent تشغّل الخادم عند تسجيل الدخول إلى macOS.
- يدعم التطبيق تصدير CSV متوافقاً مع Excel ونسخة JSON احتياطية، مع استعادة نسخة JSON من جهاز آخر. الاستعادة تستبدل قاعدة البيانات الحالية بعد تأكيد المستخدم؛ صدّر نسخة أولاً إذا أردت الاحتفاظ بالبيانات الحالية.

## قواعد البيانات والاستيراد
- يحفظ التطبيق الرمز الوطني والاحتياج السنوي كما وردا في المصدر، مع اسم الملف والورقة ورقم الصف.
- يحاول اكتشاف رؤوس الأعمدة متعددة الصفوف في الملازم، ويفضل أعمدة الاحتياج لعام 2026 على أعمدة المصروفات التاريخية.
- الملفات المتطابقة تُتجاوز بواسطة بصمة SHA-256 عند توفر Web Crypto.
- المواد ذات الرمز/الاحتياج الناقص، والرموز المكررة، والاحتياج الصفري تُعرض للتدقيق.
- احتياج 3 أشهر للدواء و6 أشهر للمستلزمات هو حساب أولي (السنوي ÷ 4 أو ÷ 2). المواد المعتمدة على أعداد المرضى أو أوزانهم لا تحسب تلقائياً. لا تُقرّب الكميات ولا تُعتمد رسمياً دون مراجعة وحدة التعبئة والضوابط.

## المستندات
تمت مراجعة النصوص والجداول مقابل نموذجي Word المرفقين؛ توقيع التخويل باسم مدير المستشفى، بينما الاعتذار يضع توقيع الصيدلاني وموضع مدير قسم الصيدلة. الطباعة مسودة تحتاج مراجعة بصرية نهائية ومقارنة صفحة بصفحة مع ملفات Word الأصلية قبل الاعتماد.

## اختبارات
شغّل \`node tests/import-parser.test.js\` للتحقق من اكتشاف الأعمدة في نماذج ملازم مختلفة.

## حدود النسخة الحالية
- قاعدة البيانات المركزية الحالية ملفات JSON محلية على Mac وليست قاعدة بيانات SQL؛ يجب تضمين `data/private/` في النسخ الاحتياطية الآمنة.
- الأكواد ثابتة ومشتركة؛ هي مناسبة كبوابة دخول بسيطة وليست مصادقة قوية. غيّرها في `server.js` إذا تسربت، ولا تضع بيانات صحية حساسة في هذا النموذج.
- الاستيراد والنتائج تحتاج تدقيقاً بشرياً، خصوصاً الصفوف التي تخلو من الرمز الوطني أو الكمية.

## الصيانة والاختبارات
- المصدر الأساسي للواجهة المشتركة هو مجلد المشروع الرئيسي. بعد تعديل app.js أو forms-addon.js أو styles.css أو catalog-seed.js أو sw.js شغّل sh scripts/sync-android-assets.sh لمزامنتها إلى أصول Android دون استبدال ملفات Android الخاصة.
- شغّل sh scripts/check.sh لفحوص الصياغة، وتطابق الأصول، واختبارات الاستيراد والواجهة وواجهات API. يتطلب اختبار API أن يكون خادم التطوير متاحاً على 127.0.0.1:8101.
- لا يغيّر هذا التنظيم أكواد الدخول أو أرقام المستخدمين أو طريقة فصل سجلاتهم.
